Badge custom fonts
==================

Place ITC Avant Garde Gothic Demi font file here for badge design & print.

Supported filenames (first match wins):
  - avantgarde_demi.ttf
  - ITCAvantGardeGothic-Demi.ttf
  - ITCAvantGardeGothicDemi.ttf
  - ITCAvantGardeStd-Demi.otf
  - ITC Avant Garde Gothic Demi.ttf

Font: ITC Avant Garde Gothic Demi Regular (TrueType)
After copying the file, restart the Node app so server-side badge images use the font.
